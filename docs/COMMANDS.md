# 💬 Справочник команд

[⬅ Назад к README](../README.md)

</div>

---

Набери `/` в поле ввода — появится выпадающий список команд.

| Клавиша   | Действие                       |
| --------- | ------------------------------ |
| `↑` / `↓` | Выбор команды в списке         |
| `Tab`     | Автодополнить выбранную команду|
| `Enter`   | Выполнить                      |
| `Esc`     | Выход из приложения            |

## Команды

### `/lang`
Переключает язык интерфейса между русским и английским. Очищает историю сообщений (условия погоды перерисовываются на новом языке).

### `/units`
Переключает систему единиц: метрические (°C, m/s) ↔ имперские (°F, mph). Текущая погода перезапрашивается в новых единицах. Выбор сохраняется в конфиге.

### `/save`
Добавляет текущий город в избранное. Если город уже сохранён — сообщает об этом. Избранное хранится в `~/.openweather/config.json`.

### `/list`
Показывает список сохранённых городов. Если пусто — подсказывает использовать `/save`.

### `/clear`
Очищает историю сообщений (лог диалога). Хедер с текущей погодой остаётся.

### `/help`
Выводит список всех доступных команд с описаниями.

### `/quit`
Завершает работу приложения. Эквивалент `Esc` / `Ctrl+C`.

## Обычный ввод

Любой текст без `/` трактуется как название города. После `Enter` запускается геокодинг и загрузка прогноза, результат добавляется в историю.
